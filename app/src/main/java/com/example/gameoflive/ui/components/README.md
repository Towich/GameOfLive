# Дизайн-система EvoSim

Этот пакет содержит переиспользуемые компоненты дизайн-системы для приложения EvoSim.

## Компоненты

### 1. AnimatedParticles
Анимированные частицы для создания динамичного фона.

**Использование:**
```kotlin
AnimatedParticles()
```

**Особенности:**
- Автоматически создает 25 частиц с разными типами (TEAL, ORANGE, WHITE)
- Частицы анимируются по случайным траекториям
- Использует константы из `DesignConstants`

### 2. GradientBackground
Градиентный фон, используемый во всех экранах приложения.

**Использование:**
```kotlin
GradientBackground {
    // Ваш контент здесь
}
```

**Цвета градиента:**
- Верх: `#1a1a2e` (темно-синий)
- Середина: `#16213e` (синий)
- Низ: `#0f3460` (светло-синий)

### 3. AnimatedButton
Анимированная кнопка с поддержкой различных состояний.

**Использование:**
```kotlin
AnimatedButton(
    text = "Текст кнопки",
    icon = Icons.Default.PlayArrow,
    onClick = { /* действие */ },
    isPrimary = true // или false
)
```

**Параметры:**
- `text`: Текст кнопки
- `icon`: Иконка (опционально)
- `onClick`: Обработчик клика
- `isPrimary`: Основная или вторичная кнопка
- `enabled`: Активна ли кнопка
- `width`: Ширина кнопки (по умолчанию `MENU_BUTTON_WIDTH`)
- `height`: Высота кнопки (по умолчанию `MENU_BUTTON_HEIGHT`)

**Особенности:**
- Анимации при наведении и нажатии
- Автоматическое изменение цвета в зависимости от типа
- Поддержка иконок
- Настраиваемые размеры

## Цветовая палитра

### Основные цвета:
- **Primary**: `#4ECDC4` (бирюзовый)
- **Secondary**: `#2C3E50` (темно-синий)
- **Background**: Градиент от `#1a1a2e` до `#0f3460`
- **Text Primary**: `#FFFFFF` (белый)
- **Text Secondary**: `#B8B8B8` (серый)
- **Error**: `#E74C3C` (красный)

### Дополнительные цвета:
- **Orange**: `#FF6B6B` (оранжевый)
- **Gray Light**: `#95A5A6` (светло-серый)
- **Gray Dark**: `#7F8C8D` (темно-серый)

## Константы дизайна

Все константы определены в `DesignConstants`:
- Размеры кнопок
- Отступы
- Радиусы скругления
- Размеры шрифтов
- Длительности анимаций
- Параметры частиц

## Принципы использования

1. **Консистентность**: Всегда используйте компоненты дизайн-системы вместо создания собственных
2. **Переиспользование**: Избегайте дублирования кода
3. **Адаптивность**: Компоненты должны работать на разных размерах экранов
4. **Доступность**: Учитывайте потребности пользователей с ограниченными возможностями
